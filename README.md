# 🇨🇮 KICKORA — Le Temple de la Sneaker en Côte d'Ivoire

**KICKORA** est une boutique e-commerce de sneakers et baskets, conçue pour le marché ivoirien (Abidjan et intérieur du pays), avec paiement mobile money et livraison locale.

> 👨‍💻 Créé par [Bakayoko Sory](https://portfolio-gules-six-86.vercel.app/)

---

## ✨ Fonctionnalités

- 🛒 Panier interactif avec sélection de pointures
- 💳 Paiement Wave CI, Orange Money, MTN MoMo, Cash à la livraison
- 🚚 Livraison express Abidjan & expédition intérieur pays
- 💬 Confirmation de commande via WhatsApp
- 📦 Base de données Supabase (Cloud)
- 🔒 Headers de sécurité HTTP (CSP, HSTS, X-Frame-Options)
- 📈 SEO optimisé pour Google Côte d'Ivoire

---

## 🛠️ Stack Technique

- **Frontend** : HTML, CSS, JavaScript vanilla
- **Base de données** : Supabase (PostgreSQL)
- **Backend** : PHP / MySQL (API REST)
- **Déploiement** : Vercel
